       VALID_FEEDBACK_TYPES = frozenset({"global", "split", "merge", "move_item", "instructional"})

    5. Module-level prompt template (exact content from RESEARCH.md Pattern 9):
       ```python
       _PARSE_FEEDBACK_PROMPT = """
       You are parsing oracle feedback in a clustering conversation.
       Current clusters: {cluster_summary}
       Oracle said: "{raw_text}"

       Extract ALL feedback intents as a JSON array. Each item has exactly one of these schemas:
       - {{"type": "global", "instruction_text": "..."}}
       - {{"type": "split", "cluster_id": <int>, "seed_item_ids": [<int>, ...]}}
       - {{"type": "merge", "cluster_a_id": <int>, "cluster_b_id": <int>}}
       - {{"type": "move_item", "item_id": <int>, "target_cluster_id": <int>}}
       - {{"type": "instructional", "instruction_text": "..."}}

       Rules:
       - Return ONLY a JSON array. No markdown. No explanation.
       - If no feedback: return []
       - Compound messages produce multiple array items.
       - seed_item_ids may be [] if oracle names no specific items.
       - cluster_id values must exist in the current cluster list.
       """
       ```

    6. Helper function `_build_cluster_summary(state: ClusteringState) -> str`:
       Returns a compact string like "0: Alpha, 1: Beta, 2: Gamma" listing active cluster IDs and names.
       No I/O. Pure function.

    7. Helper function `_build_delta(item: dict, valid_cluster_ids: set[int]) -> FeedbackDelta`:
       Maps one parsed JSON item to a FeedbackDelta. Asserts:
       - `"type" in item and item["type"] in VALID_FEEDBACK_TYPES`
       - For split/merge/move_item: all referenced cluster_ids are in valid_cluster_ids
       Construct and return the appropriate frozen dataclass based on item["type"].
       No try/except here — let KeyError crash if LLM omits a required field (fail loudly).

    8. Public function `parse_feedback(raw_text: str, state: ClusteringState, client: object) -> list[FeedbackDelta]`:
       - Build cluster summary
       - Build prompt using _PARSE_FEEDBACK_PROMPT.format(...)
       - Call client.messages.create(model="claude-haiku-4-5", max_tokens=512, messages=[...])
       - Extract response text: response.content[0].text.strip()
       - Strip markdown code fences (same pattern as cluster_naming.py)
       - Try/except is PERMITTED here for json.loads only:
         ```python
         try:
             raw_items = json.loads(cleaned_text)
         except json.JSONDecodeError:
             raise  # fail loudly — do not swallow
         ```
       - Assert raw_items is a list: `assert isinstance(raw_items, list)`
       - Build valid_cluster_ids set: `{c.id for c in state.clusters}`
       - Map each item to FeedbackDelta via `_build_delta(item, valid_cluster_ids)`
       - Return the list

    IMPORTANT: Only one `except` clause in the entire file — the `json.JSONDecodeError` re-raise above.
    No other try/except anywhere in this file.
    Do NOT call the LLM if raw_text is empty — return [] immediately (fast path).
