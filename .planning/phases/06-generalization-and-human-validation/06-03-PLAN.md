    4. _run_study_background(session_id: str) function (runs in worker thread):
       - Load records + build initial clustering (same as _run_conversation_background:
         EmbeddingStore.load("embeddings/embeddings.npy"), ClusteringBackend setup,
         initial HDBSCAN/KMeans fit, cluster naming)
       - Compute UMAP projection; emit "study_projection" event with faceted payload:
           coords, cluster_colors, global_bounds {x_min, x_max, y_min, y_max},
           per_cluster {cluster_id: {item_ids: [...], name: str, description: str}}
       - Store state + store + coords in _study_sessions[session_id]
       - Emit "study_state" event: clusters list with names, descriptions, item_ids,
         top 8 sample items per cluster (slice cluster.item_ids[:8])
       - Loop: while turn_index < STUDY_MAX_TURNS:
           a. Emit "study_awaiting_feedback" event
           b. Wait on feedback_event (threading.Event.wait() — blocks until human sends)
           c. feedback_event.clear(); human_text = feedback_queue.pop(0)
           d. Run satisfaction detection (anthropic call — try/except APIError only):
              prompt = f"Does this message indicate the user is satisfied...{human_text}"
              satisfied = response.content[0].text.strip().upper() == "YES"
           e. If satisfied: emit "study_satisfaction_detected" event with text
              "It looks like you're satisfied with the clustering. End session? Reply 'yes' to end."
              Wait for confirmation feedback_event again; confirm_text = feedback_queue.pop(0)
              if confirm_text.strip().lower() in ("yes", "y", "yeah", "yep"):
                  _end_study_session(session_id, convergence_reason="oracle_satisfied"); return
              else:
                  # Participant said No — emit current study_state and resume main loop from step 4a
                  asyncio.run_coroutine_threadsafe(emitter.emit("study_state", current_state_payload), _loop)
                  continue
           f. Parse human_text into FeedbackDelta list via parse_feedback(human_text, state)
           g. Apply f_next_state(state, deltas) -> new_state
           h. Write state.json: _write_session_state(new_state, session_dir)
           i. Append to audit_log.jsonl (call append_to_audit_log)
           j. DB: insert turn row via src/db/turns.create(...)
           k. Increment turn_index; update session state
           l. Emit "study_state" update
       - If loop exits (turn_budget): _end_study_session(session_id, "turn_budget")

    5. _end_study_session(session_id, convergence_reason):
       - Update experiments row with total_turns + convergence_reason + end_timestamp
       - db.close(); emit "study_ended" event with convergence_reason
       - Mark session as ended in _study_sessions

    6. SocketIO event handler @sio.event "study_feedback":
       - data = {"session_id": str, "text": str}
       - Assert session_id in _study_sessions; assert "text" in data
       - Append data["text"] to _study_sessions[session_id]["feedback_queue"]
       - _study_sessions[session_id]["feedback_event"].set()

    - emit cross-thread via emitter (asyncio.run_coroutine_threadsafe via SocketIOEmitter)

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| participant browser → SocketIO "study_feedback" | Participant input is untrusted; parse_feedback validates feedback intent; no eval() or innerHTML with user text |
| POST /study/sessions body | Researcher-provided dataset_path; assert exists before use; no path traversal beyond assertion |
| satisfaction detection LLM response | Untrusted LLM output; only YES/NO checked; treat any non-YES as not satisfied |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-03-01 | Spoofing | study_feedback SocketIO event — no participant auth | accept | study is researcher-controlled session with known URL; auth deferred (not in scope) |
| T-06-03-02 | Tampering | dataset_path in POST /study/sessions body | mitigate | assert os.path.exists(dataset_path) before loading; does not write to dataset_path |
| T-06-03-03 | Information Disclosure | session state visible in SocketIO events | accept | study UI is researcher-hosted local tool; no sensitive PII in cluster assignments |
| T-06-03-04 | Denial of Service | participant sends empty/garbage feedback in loop | mitigate | parse_feedback on empty string returns []; loop continues; STUDY_MAX_TURNS cap limits turns |
| T-06-03-05 | Elevation of Privilege | innerHTML with participant feedback text | mitigate | render participant feedback text as textContent (not innerHTML) in study.js |
| T-06-03-SC | Tampering | npm/pip installs | mitigate | no new packages; existing FastAPI, socketio, anthropic already in requirements.txt |
</threat_model>
