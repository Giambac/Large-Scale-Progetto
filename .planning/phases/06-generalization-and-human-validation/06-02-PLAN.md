    Create examples/evaluate_mapping.py with the following structure:

    CLI arguments:
      --session-dir  REQUIRED  path to sessions/<ts>/ directory (contains state.json + audit_log.jsonl)
      --n-items      OPTIONAL  number of held-out items to evaluate (default: 25)
      --held-out     OPTIONAL  path to held-out JSONL file (default: dataset/held_out.jsonl)
      --embeddings   OPTIONAL  path to embeddings .npy file (default: embeddings/embeddings.npy)
      --seed         OPTIONAL  random seed for held-out sample selection (default: 42)
      --json         OPTIONAL  emit JSON array instead of table

    main() logic:
    1. Parse args. Assert session_dir exists and contains state.json and audit_log.jsonl.
    2. Load state: read state.json, call deserialize_state(line) -> ClusteringState.
    3. Load embedding_store: EmbeddingStore.load(args.embeddings).
    4. Load held-out records from args.held_out (same JSONL loading pattern as run_baseline.py).
       Assert held-out file has not been modified: do NOT compute or verify SHA-256 at runtime —
       the constraint is on WRITE access only (never modify). Just assert os.path.exists(held_out_path).
    5. Sample n_items records deterministically: random.Random(args.seed).sample(records, args.n_items).
       If len(records) < args.n_items: use all records and call deviation("held_out_smaller_than_n_items", ...).
    6. Build OracleRuleSet: call extract_oracle_rules(audit_log_path).
    7. For each mapping strategy name in sorted(MAPPING_REGISTRY.keys()):
       a. Instantiate strategy: strategy_cls = MAPPING_REGISTRY[name]; strategy = strategy_cls()
       b. Get ground-truth labels: for each sampled item, make a direct anthropic.Anthropic()
          client call (try/except anthropic.APIError only) with prompt:
          "You are a cluster labeler. Assign this item to exactly one cluster.
           Clusters: {comma-separated 'ID: name' list from state.clusters}
           Item text: {item_text}
           Reply with ONLY the cluster ID integer."
          Parse response.content[0].text.strip() as int. If parse fails or value not in cluster IDs:
          call deviation("oracle_labeling_invalid_cluster_id", ...) and skip this item.
       c. Get mapping prediction: strategy.assign(item_text, state, rule_set, embedding_store)
          Returns str cluster_id. Convert to int for comparison.
       d. agreement = int(str(prediction) == str(oracle_label))  (1 if match, 0 otherwise)
       e. Collect agreement values list (list[float], 1.0 or 0.0).
       f. accuracy = mean(agreement_values)
       g. If len(agreement_values) >= 5: lo, hi = compute_bootstrap_ci(agreement_values, seed=args.seed)
          else: lo, hi = accuracy, accuracy
    8. Build entries list and print table (or JSON if --json).

    Table format (exact column widths from 06-CONTEXT.md):
      "Mapping strategy    | Accuracy | N items | 95% CI"
      "--------------------|----------|---------|--------"
      per row: f"{name:<20}| {accuracy:>8.2f} | {n:>7} | [{lo:.2f}–{hi:.2f}]"

    Do NOT modify held_out.jsonl at any point. No DB writes in this script.
    No try/except except at the two anthropic.APIError sites (ground-truth labeling
    and any future LLM calls in LLMMappingStrategy — those are inside the strategy).
