    4. LLMMappingStrategy — implements MappingProtocol:
       - assign() builds a prompt: cluster names + descriptions (all clusters in state.clusters)
         + OracleRuleSet fields (formatted as bullet lists) + item_text
         + instruction "Which cluster ID does this item belong to? Reply with ONLY the
           cluster ID integer, nothing else."
       - One anthropic.Anthropic() client call per assign() call (claude-haiku-4-5, max_tokens=8)
       - try/except anthropic.APIError only — all other exceptions propagate
       - Parse response.content[0].text.strip() as cluster ID; assert parsed value is an integer
         string matching one of the cluster IDs in state.clusters — if not, raise ValueError
         with "LLMMappingStrategy: LLM returned unknown cluster id {value!r}"
       - __init__ accepts no args (consistent with StrategyProtocol pattern)

    5. CentroidMappingStrategy — implements MappingProtocol:
       - assign() computes cluster centroids from embedding_store:
         For each cluster in state.clusters, collect item_ids (cluster.item_ids),
         retrieve their embeddings via embedding_store.get(item_id), compute mean
         (numpy mean along axis=0) — this is the centroid.
         If any cluster has 0 hard-assigned items (cluster.item_ids is empty):
           raise ValueError(f"cluster {cluster.id} has no items — cannot compute centroid")
       - Embed new item: use sentence_transformers.SentenceTransformer(EMBEDDING_MODEL)
         loaded lazily in __init__ (self._model = SentenceTransformer(EMBEDDING_MODEL))
         Call self._model.encode([item_text], convert_to_numpy=True)[0] to get vector
       - Assign to nearest centroid by cosine similarity:
         cosine_sim = np.dot(item_vec, centroid) / (np.linalg.norm(item_vec) * np.linalg.norm(centroid) + 1e-10)
         Return str(cluster.id) for the cluster with highest cosine_sim
       - __init__() loads SentenceTransformer(EMBEDDING_MODEL) — same model as embedding_store.py

    6. MAPPING_REGISTRY = {"llm": LLMMappingStrategy, "centroid": CentroidMappingStrategy}
