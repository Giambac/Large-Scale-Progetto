| Boundary | Description |
|----------|-------------|
| run_conversation caller → events_path | Caller-supplied events_path could point outside session dir; no path validation in v1 |
| global_instructions accumulator → oracle system prompt | Instructions accumulate across all turns in a session; no deduplication or length cap in v1 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-04-01 | Tampering | events.jsonl write | accept | events_path defaults to same directory as log_path; researcher-controlled in v1 |
| T-03-04-02 | Information Disclosure | oracle_init event logging | accept | logs researcher-configured parameters only (preferred_k, noise rates); no user PII |
| T-03-04-03 | Denial of Service | global_instructions growing unbounded | accept | Phase 3 has no cap; deferred to Phase 5 if ablation reveals quality degradation from prompt length |
| T-03-04-04 | Tampering | audit_log.jsonl integrity | mitigate | _write_event writes ONLY to events_path (separate file); load_audit_log() is never called on events.jsonl; Pitfall 5 is fully resolved by this design |
