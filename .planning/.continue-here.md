## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| oracle_init/drift_event in audit_log.jsonl | load_audit_log() calls deserialize_state() on every line and asserts turn_index — non-state records cause AssertionError crash | advisory | Write oracle_init and drift_event to sessions/<timestamp>/events.jsonl sidecar ONLY — never to audit_log.jsonl. Already enforced in Phase 3. |
| cognitive_load dead code (CR-01) | Loop computes a value but doesn't pass it to callers — silent behavior gap. Fixed in Phase 3 but watch for similar wiring gaps in Phase 4 when wiring judge metrics. | advisory | Verify that every value computed in run_conversation() that a new agent needs is actually passed through. |
| OracleProtocol.reply() missing params (WR-04) | Protocol is stale — lacks global_instructions and cognitive_load. Non-OracleAgent oracles silently skip these features. | advisory | Phase 4 may want to extend OracleProtocol.reply() signature if Judge Agent reads protocol-level oracle data. |
